# Sistema de Gerenciamento de Alunos em Java

Projeto desenvolvido em Java para praticar lógica de programação, vetores, estruturas de repetição e manipulação de dados.

## Funcionalidades

- Cadastro de alunos
- Registro de duas notas por aluno
- Listagem de alunos
- Cálculo de média individual
- Cálculo de média da turma
- Verificação da maior média
- Verificação da menor média
- Relatório de aprovados, recuperação e reprovados

## Tecnologias utilizadas

- Java
- Eclipse IDE

## Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de fortalecer conhecimentos em programação estruturada utilizando Java, trabalhando conceitos importantes como:

- Arrays
- Condições
- Loops
- Busca de dados
- Cálculos de média
- Estrutura de menus
